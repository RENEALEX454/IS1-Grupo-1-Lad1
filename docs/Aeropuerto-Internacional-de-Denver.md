
# Aeropuerto Internacional de Denver 1994

## Análisis de un suceso clave de la Crisis del Software

## Introducción


El Aeropuerto Internacional de Denver fue un proyecto de gran importancia que presentó dificultades relacionadas con el desarrollo de software. Uno de los elementos más ambiciosos del proyecto fue la creación de un **sistema automatizado para el manejo del equipaje**.

El objetivo era utilizar tecnología para transportar las maletas automáticamente desde los mostradores de registro hasta los aviones correspondientes.

## El sistema automatizado de equipaje

El sistema automatizado de equipaje debía coordinar diferentes elementos, como computadoras, sensores, cintas transportadoras y vehículos automatizados.

La idea era que el sistema pudiera manejar grandes cantidades de equipaje de manera rápida y eficiente. Sin embargo, la gran cantidad de componentes que debían funcionar al mismo tiempo hizo que el proyecto fuera **muy complejo**.

## Problemas encontrados

Durante el desarrollo del sistema se presentaron varios problemas:

* **Complejidad del sistema:** era necesario coordinar una gran cantidad de equipos y componentes.
* **Problemas de integración:** los diferentes elementos del sistema tenían que funcionar correctamente entre sí.
* **Retrasos:** las dificultades técnicas afectaron el calendario del proyecto.
* **Cambios en los requisitos:** durante el desarrollo se realizaron modificaciones que aumentaron la complejidad.
* **Aumento de costos:** los problemas y retrasos provocaron gastos adicionales.
* **Problemas durante las pruebas:** fue difícil comprobar que todo el sistema funcionara correctamente antes de su utilización.

## Relación con la Crisis del Software

El caso del Aeropuerto Internacional de Denver es un ejemplo relacionado con la **Crisis del Software**, debido a las dificultades que pueden aparecer al desarrollar proyectos de software grandes y complejos.

La Crisis del Software se caracterizó por problemas como **retrasos, costos elevados, dificultades para cumplir los requisitos y problemas de planificación**.

En este proyecto, la complejidad del sistema automatizado de equipaje demostró que desarrollar un sistema de gran tamaño requiere una planificación adecuada y pruebas constantes.

## Suceso clave

Uno de los sucesos más importantes fue que el sistema automatizado de equipaje no estuvo listo para funcionar de acuerdo con el calendario original.

Los problemas del sistema contribuyeron a retrasos en la apertura del aeropuerto. Esto demuestra que una falla o retraso en un sistema de software puede afectar directamente a todo un proyecto.

## Consecuencias

Los problemas relacionados con el sistema automatizado tuvieron diferentes consecuencias:

* **Retraso en la apertura del aeropuerto.**
* **Incremento de los costos del proyecto.**
* Necesidad de realizar modificaciones y pruebas adicionales.
* Reducción de la confianza en el sistema automatizado.
* Necesidad de utilizar soluciones alternativas para el manejo del equipaje.

## Lecciones aprendidas

El caso del Aeropuerto Internacional de Denver permitió identificar varias lecciones importantes para la ingeniería de software:

* **Planificar correctamente** los proyectos antes de comenzar.
* Definir claramente los requisitos.
* Realizar **pruebas continuas** durante el desarrollo.
* Controlar los cambios en los requisitos.
* Identificar los riesgos desde las primeras etapas.
* Mantener una buena comunicación entre los equipos.
* Dividir los sistemas grandes y complejos en partes más fáciles de controlar.
* Comprobar la integración entre el software y el hardware.

## Importancia para la Ingeniería de Software

Este caso demuestra que la tecnología por sí sola no garantiza el éxito de un proyecto. También es necesario contar con una **buena planificación, organización, comunicación, control de cambios y pruebas**.

Los problemas del Aeropuerto Internacional de Denver muestran la importancia de aplicar buenas prácticas de ingeniería de software, especialmente cuando se desarrollan sistemas de gran escala.

## Conclusión

El **Aeropuerto Internacional de Denver 1994** es un caso importante para comprender los problemas relacionados con la Crisis del Software.

Las dificultades del sistema automatizado de equipaje demostraron que los proyectos grandes y complejos necesitan una planificación adecuada, requisitos claros, pruebas constantes y un buen control durante todo el proceso de desarrollo.

Este caso dejó como enseñanza que es necesario identificar los riesgos y problemas desde las primeras etapas para evitar retrasos, costos adicionales y fallas en el funcionamiento del sistema.
